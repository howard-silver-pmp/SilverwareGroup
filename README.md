## Approved brand palette

- SRG Navy: `#032B60`
- SRG Teal: `#04839D`
- SRG Silver: `#9A9DA2`
- White: `#FFFFFF`

The shared stylesheet defines these colors as CSS custom properties. Light
backgrounds, borders, and secondary text use transparent tints of the approved
colors rather than unrelated accent colors.

The home-page pillars and service-card icons retain a small supplemental
multicolor palette for visual differentiation. These accent colors are limited
to the icon tiles; navigation, typography, buttons, section backgrounds, and
other structural elements follow the approved SRG palette.
